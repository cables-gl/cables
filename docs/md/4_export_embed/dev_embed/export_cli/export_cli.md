# Export using the cables command line interface

[cables-cli](https://github.com/cables-gl/cables-cli) allows you to use the export form any node/npm project or the commandline of your operating system.

Check the [commandline section](../../../6_3_commandline/0_cli/cli) of the docs for more info on it's usage.

## Prerequisites

- any current version of node/npm
- an api-key created on [your settings page](https://cables.gl/settings)
