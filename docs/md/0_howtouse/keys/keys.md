

# Keyboard Shortcuts

*`[mod]` is your operating system’s primary modifier key, on Mac OS X this is `[cmd]`, on Windows `[ctrl]`.*

## Editor
- `Space`: Drag left mouse button to pan patch
- `-`: Zoom Out
- `shift + !`: debug
- `+`: Zoom In
- `shift + +`: Zoom In
- `&#x3D;`: Zoom In
- `[mod] + a`: Select all ops in current subpatch
- `a`: Arrange selected ops
- `shift + a`: Compress selected ops vertically
- `c`: Center Selected Ops
- `d`: Disable Op
- `[mod] + d`: Duplicate selected ops
- `e`: Edit op code
- `p`: previous op
- `shift + p`: previous op
- `t`: Set Title
- `u`: Goto parent subpatch
- `x`: Unlink selected ops
- `shift + x`: Unlink selected ops first ports only
- `y`: Cut Cables

## Global
- `Space`: Play/Pause timeline
- `[mod] + Space`: Rewind and play Timeline
- `Space`: Play/Pause timeline
- `[mod] + ,`: Patch Settings
- `[mod] + b`: Toggle Tab Area
- `shift + e`: shift-e editor
- `[mod] + enter`: Cycle size of renderer between normal and Fullscreen
- `shift + enter`: Cycle patchfield visibility
- `escape`: Open &quot;Op Create&quot; dialog (or close current dialog)
- `shift + escape`: Open &quot;Op Create&quot; dialog (or close current dialog)
- `[mod] + escape`: Toggle Tab Area
- `[mod] + f`: Find/Search in patch
- `o`: Toggle Overlays
- `[mod] + p`: Open Command Palette
- `[mod] + shift + s`: Save patch as new patch
- `[mod] + s`: Save patch
- `tab`: cycle tab
- `u`: undo
- `shift + u`: redo
- `[mod] + z`: undo
- `[mod] + shift + z`: redo

## Keyboard Navigation
- `a`: Add op to port
- `arrowdown`: Move down
- `arrowleft`: Move left
- `arrowright`: Move right
- `arrowup`: Move up
- `enter`: Select op
- `shift + enter`: Add op to selection
- `g`: Go to: g topmost op, w jump to op, s top of branch, e bottom of branch
- `i`: Insert op into cable
- `s`: Edit port in param panel

## Timeline
- `Space`: Drag left mouse button to pan timeline
- `[mod] + Space`: Rewind and play
- `,`: Rewind one frame
- `.`: Forward one frame
- `a`: Move keys to cursor
- `[mod] + a`: Select all keys
- `backspace`: Delete selected keys
- `c`: Center cursor
- `d`: Delete Selected Keys
- `delete`: Delete selected keys
- `f`: Zoom to all or selected keys
- `j`: Go to previous keyframe
- `k`: Go to next keyframe
