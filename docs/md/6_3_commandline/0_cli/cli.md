# cables-cli

You can use [cables-cli](https://github.com/cables-gl/cables-cli) to export/import your
patches and upload assets using the command line.

To install it, run:

`npm install -g @cables/cables`

A simple example of an [HTML Export](../../4_export_embed/dev_embed/export_zip/export_zip) of your patch can then be created with:

`cables export -d "my-patch" -p pQpie9`

Use `--help` to get more information or check the [documentation](https://github.com/cables-gl/cables-cli)
in the the repository.
